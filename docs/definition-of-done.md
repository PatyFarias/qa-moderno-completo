# Definition of Done — qa-moderno-completo
Uma história só é considerada "Done" quando TODOS os itens abaixo são verdadeiros:
  - [ ] Código revisado e aprovado via Pull Request
  - [ ] Testes unitários cobrindo a lógica de negócio nova (Dev)
  - [ ] Testes de API cobrindo os contratos alterados/criados (QA)
  - [ ] Cenários de borda e negativos documentados e testados
  - [ ] Pipeline de CI passando sem falhas (build + testes + lint)
  - [ ] Documentação (README/docs) atualizada quando aplicável
  - [ ] Sem regressão identificada na suíte automatizada existente
